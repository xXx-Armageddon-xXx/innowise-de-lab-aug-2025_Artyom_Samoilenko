Задание 4: Игра «Угадай число»
    
    Описание задания: Напишите программу, которая «загадывает» случайное целое число в
    диапазоне от 1 до 5. Пользователь пытается его отгадать. Программа должна сравнить
    число пользователя с загаданным и вывести одно из трех сообщений: 
        ● «Ты угадал!», если числа совпали.
        ● «Слишком много!», если число пользователя больше загаданного.
        ● «Слишком мало!», если число пользователя меньше загаданного.
